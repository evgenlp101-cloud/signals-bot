# Сигналы в Telegram без компьютера

Бот запускается на серверах GitHub по расписанию, считает индикаторы и присылает сообщение в Telegram, когда появляется сигнал. Ноутбук выключен, телефон получает уведомления.

Всё бесплатно: GitHub даёт 2000 минут в месяц на публичные репозитории, а один запуск занимает около 20 секунд.

---

## Шаг 1. Создать бота в Telegram

1. Найди в Telegram **@BotFather**, отправь `/newbot`
2. Придумай имя и логин бота (логин должен заканчиваться на `bot`)
3. BotFather пришлёт **токен** вида `123456789:AAE-xxxxxxxxxxxxxxxxxx` — сохрани его
4. Найди своего бота в поиске и напиши ему любое сообщение (например «старт») — без этого он не сможет тебе писать

## Шаг 2. Узнать свой chat_id

Открой в браузере, подставив свой токен:

```
https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
```

Найди в ответе `"chat":{"id":123456789` — это число и есть **chat_id**.

Если ответ пустой — напиши боту сообщение и обнови страницу.

## Шаг 3. Создать репозиторий

1. Зайди на github.com, зарегистрируйся, если аккаунта нет
2. Нажми **New repository**, назови `signals-bot`, оставь **Public** (для приватных Actions платные), нажми **Create**
3. Нажми **uploading an existing file** и перетащи туда `signals.py` и `README.md`
4. Отдельно создай папку с workflow: нажми **Add file → Create new file**, в поле имени введи:

```
.github/workflows/signals.yml
```

(слэши сами создадут папки), вставь содержимое файла `signals.yml` и нажми **Commit**

## Шаг 4. Вписать секреты

В репозитории: **Settings → Secrets and variables → Actions**

Вкладка **Secrets**, кнопка **New repository secret** — добавь два:

| Имя | Значение |
|---|---|
| `TG_TOKEN` | токен от BotFather |
| `TG_CHAT` | твой chat_id |

Если хочешь валютные пары, добавь третий: `TD_KEY` — ключ с twelvedata.com.

Вкладка **Variables**, кнопка **New repository variable** — настройки (необязательно):

| Имя | Пример | По умолчанию | Что делает |
|---|---|---|---|
| `SYMBOLS` | `BTCUSDT,ETHUSDT` | `BTCUSDT,ETHUSDT` | какие пары отслеживать |
| `INTERVAL` | `1h` | `1h` | рабочий таймфрейм |
| `THRESHOLD` | `3` | `3` | сколько индикаторов должны сойтись |
| `HTF_FILTER` | `on` / `off` | `on` | фильтр старшего таймфрейма |
| `TRADE_HOURS` | `7-20` | пусто | торговое окно в UTC |

Для валютных пар пиши через слэш: `EUR/USD,GBP/USD`. Можно смешивать: `BTCUSDT,EUR/USD`.

### Про фильтры

**Порог входа (`THRESHOLD`).** Сколько из пяти индикаторов должны сойтись в одну сторону. При пороге 2 бот торгует втрое чаще, но качество сигнала то же самое — проверено на 150 смоделированных рынках: преимущество на сделку не изменилось, а издержки выросли втрое. Поэтому по умолчанию 3.

**Фильтр старшего таймфрейма (`HTF_FILTER`).** Бот дополнительно загружает старший таймфрейм (для H1 это H4, для H4 — дневной) и отклоняет сигналы против большого тренда. Это единственная добавка, которая приносит действительно новую информацию: любой дополнительный осциллятор пересчитывает те же данные, что уже учтены. В сообщение добавляется отметка «✓ подтверждено трендом на 4h».

Стоит цены: одна лишняя загрузка данных на пару. Для валютных пар это удваивает расход лимита Twelve Data.

**Торговые часы (`TRADE_HOURS`).** Формат `начало-конец` в UTC. Например `7-20` — только европейская и американская сессии. Азиатская сессия обычно проходит во флэте, где сигналы хуже.

Для крипты фильтр обычно не нужен: рынок работает круглосуточно. Для форекса имеет смысл, особенно `7-20`.

## Шаг 5. Запустить

Вкладка **Actions** → слева выбери **Сигналы в Telegram** → кнопка **Run workflow**.

Через полминуты в логе будет видно, что посчиталось. Если сигнал есть — придёт сообщение.

Дальше бот работает сам каждые 30 минут.

## Настройка расписания

В файле `signals.yml` строка с `cron`:

```yaml
- cron: '*/30 * * * *'    # каждые 30 минут
- cron: '0 * * * *'       # каждый час
- cron: '*/15 * * * *'    # каждые 15 минут
- cron: '0 */4 * * *'     # каждые 4 часа
```

Разумно согласовать с таймфреймом: для `INTERVAL=1h` проверять чаще раза в 30 минут смысла нет.

**Важно:** GitHub не гарантирует точность расписания, при нагрузке запуск может задержаться на 5–15 минут. Для часовых и четырёхчасовых сигналов это неважно, для пятнадцатиминутных — чувствительно.

## Как бот решает, что слать

Сообщение уходит **только когда сигнал появился или сменил направление**. Если BUY держится пять запусков подряд — сообщение придёт один раз, а не пять.

Состояние хранится в файле `state.json`, который бот сам обновляет в репозитории после каждого запуска.

Сигнал появляется при счёте ±2 из пяти индикаторов, «сильный» — при ±3 и ADX выше 25.

## Если что-то не работает

**Workflow падает с ошибкой в шаге «Сохранить состояние»** — в Settings → Actions → General → Workflow permissions поставь **Read and write permissions**.

**Сообщения не приходят** — проверь, что написал боту первым. Бот не может начать переписку сам.

**В логе «нет данных» по паре** — проверь написание тикера: крипта слитно (`BTCUSDT`), валюты через слэш (`EUR/USD`).

**Бот перестал запускаться через несколько месяцев** — GitHub отключает расписание в репозиториях без активности. Достаточно зайти во вкладку Actions и нажать **Enable workflow**.

## Запуск на своём компьютере

Если хочешь проверить бота локально, не поднимая репозиторий:

1. Скопируй `config_local.example.py` и назови копию **`config_local.py`**
2. Впиши в неё токен и chat_id
3. Запусти: `py signals.py`

Файл `config_local.py` внесён в `.gitignore` — он не попадёт в репозиторий, даже если загрузишь папку целиком.

## Безопасность токена

Токен бота — это пароль. Кто им владеет, тот управляет ботом.

**Никогда не вписывай токен в `signals.py`, `README.md` или другой файл, который уходит в репозиторий.** GitHub публичный, а Telegram автоматически сканирует его на утёкшие токены и блокирует найденные — бот просто перестанет работать.

Правильных мест ровно два:
- **`config_local.py`** — для запуска на своём компьютере
- **GitHub Secrets** — для запуска в Actions

В скрипт встроена защита: если токен окажется внутри `signals.py` или `README.md`, бот откажется стартовать и скажет об этом.

**Если токен утёк** (попал в чат, в публичный репозиторий, на скриншот) — отзови его: @BotFather → `/mybots` → выбрать бота → **API Token** → **Revoke current token**. Старый мгновенно перестанет действовать, придёт новый.

## Ограничения, о которых стоит знать

- Сигнал — это совпадение индикаторов, а не прогноз. Проверка на 400 смоделированных рынках показала, что логика совпадения индикаторов как автомат для торговли убыточна; она полезна как фильтр «не входить против тренда и во флэте».
- Индикаторы считаются по закрытым свечам, последняя свеча ещё формируется.
- Бесплатный тариф Twelve Data — 800 запросов в сутки, при частом расписании и нескольких валютных парах лимит достижим.
